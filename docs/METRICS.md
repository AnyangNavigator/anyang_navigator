# 공급 지표 규격 (팀 공통)

`/dashboard`·`/simulator`가 지금까지 재던 건 **수요**(사회조사 "향후 필요" 응답률)
하나뿐이다. `data/facilities_*.csv` 6종을 **공급** 지표로 연결한다. 3개 트랙
(지도·시뮬레이터·코어)이 이 규격을 공유한다 — 각자 다른 방식으로 정규화하지 말 것.

## 공통 원칙

1. **좌표 → 행정동 매핑은 `app/geo.dong_for_point()` 하나만 쓴다.** 새로 짜지 말 것.
2. **정규화 단위** — `app/facilities.supply_by_dong()`이 반환하는 형태:
   | 시설 | 지표 | 근거 |
   |---|---|---|
   | 공영주차장·도서관·어린이집·약국 | 인구 **1,000명당 개소수** | 생활SOC 3개년 계획 공급 기준 |
   | 도시공원 | **1인당 공원면적(㎡)** — `PARK_AR` 합 / 인구 | WHO 권장 9㎡, 도시계획시설 결정기준 |
   | 병원 | 인구 **1,000명당 병상수** — `sickbd_cnt` 합 / 인구 | 보건의료 접근성 표준 |
3. **매핑 실패분**(`dong is None`)은 집계에서 제외하고, `unmapped_ratio()`로 품질을
   기록한다. 현재 실패율: 주차 0% / 도서관 0% / 공원 1.4% / 어린이집 4.9% /
   병원 0% / 약국 1.0%.
   - **병원**: `bsn_state_nm`이 "영업"을 포함하는 행만 집계(원본 47행 중 폐업·전출 17행 제외).
     `FacilitySpec.status_col`로 CSV별 지정.
   - **공원 면적 주의**: 산지형 대형공원(예: 생태예술공원 3.28㎢)이 특정 동의 1인당
     면적을 지배할 수 있음. 지도·시뮬레이터에 노출 시 "특정 대형공원 영향" 주석 권장.
4. **격차 서사** — 공급도 수요와 같은 방향으로 본다:
   `공급격차 = 동안구 평균 공급 − 만안구 평균 공급` (양수면 만안구가 공급 부족).
   수요격차(만안 필요도 높음)와 공급격차(만안 공급 낮음)가 **같이** 크면 최우선 투자 대상.

## 새 시설 CSV 추가하는 법

`app/facilities.py`의 `REGISTRY`에 한 줄:
```python
"school": FacilitySpec("school", "facilities_school.csv", "<위도컬럼>", "<경도컬럼>", None, "학교", "개소"),
```
`weight_col`은 개소수 대신 합산할 컬럼(면적·병상수 등), 없으면 `None`.

## 공간 접근성 (2SFCA) — 이슈 #73

`supply_by_dong()`은 "행정동 안에 몇 개 있는가"만 본다. 그래서 개소수는 많아도
실제 도달 가능성은 낮을 수 있다는 걸 못 잡는다 — 공급밀도–필요도 순위상관이
기대와 반대(ρ≈+0.59, `scripts/analyze_coefficients.py`)로 나온 핵심 원인 중
하나였다. `app/access.py`가 **2단계 흡수권역법(2SFCA, Luo & Wang 2003)** 으로
"거리까지 반영한" 접근성을 계산해 이 문제를 정면으로 다룬다.

### 계산

1단계 — 시설 j의 공급-수요비 `R_j = S_j / Σ(P_k : d(k,j) ≤ d0)` (j 반경 안 모든
동 인구의 합으로 j의 용량을 나눔)
2단계 — 수요지(행정동) i의 접근성 `A_i = Σ(R_j : d(i,j) ≤ d0)` (i 반경 안 모든
시설의 R_j를 더함)

`app/facilities.supply_by_dong()`과 같은 단위계로 정규화한다(개소·병상은
1,000명당, 면적은 1인당) — 두 지표를 직접 비교할 수 있게 하기 위함.

### 가정 (반드시 명시)

- **수요지 근사**: 행정동보다 세밀한 인구 격자가 없어 **경계 폴리곤의 기하
  중심점**에 그 동 인구 전체가 있다고 본다. `app/access.dong_centroids()`.
- **직선거리**: haversine 대권거리. 실제 보행·도로 경로보다 짧게 잡힌다.
- **흡수권역 반경(d0)**: 시설 유형별 생활권 기준을 참고한 가정값
  (`app/access.CATCHMENT_RADIUS_M`/`CATCHMENT_BASIS`에 근거 명시). 정밀 실측 아님.
- **행정구역 경계 밖 시설 제외**: REGISTRY 매핑 실패분(안양시 밖 좌표)은 포함하지
  않는다 — 접경 동 주민이 실제로 누리는 시 경계 밖 시설 접근성은 못 담는다.

### 검증된 발견 — 밀도와 방향이 반대로 나온 사례

구 단위 인구가중 평균으로 비교하면 **병원·공원 2종에서 밀도와 접근성의 방향이
정반대**다 (2026-09 기준, `python -c "from app import access; ..."`로 재현 가능):

| 시설 | 밀도(만안/동안) | 접근성(만안/동안) |
|---|--:|--:|
| 보건의료시설 | 6.58 / 6.21 (만안이 약간 높음) | 4.80 / 7.50 (**동안이 뚜렷이 높음**) |
| 도시공원 | 15.6 / 3.24 (만안이 압도적) | 1.04 / 1.89 (**동안이 높음**) |

병원은 개소수로만 보면 두 구가 비슷한데, 실제로는 만안구 병상이 소수 대형시설에
쏠려 있어 다수 주민이 반경 밖이다 — **보건의료시설이 사회조사에서 구 격차가
가장 큰 항목(+18.8%p)이라는 사실과 방향이 맞아떨어진다.** 공원은 만안구 면적이
수리산 등 산지형 대형공원에 쏠려(같은 발견이 계수 도출 단계 `docs/COEFFICIENTS.md`
에도 등장) 개소 면적은 넓어도 대다수 주민의 생활권 밖이다.

전체 5개 시설(사회조사 대응분) 기준 순위상관은 ρ 0.588(밀도) → 0.467(접근성)로
**완전히 뒤집히진 않지만 유의미하게 개선**된다 — 공영주차·어린이집은 여전히
밀도와 같은 방향(만안구가 실제로 잘 분포돼 있음)이라, "모든 시설이 다 뒤집힌다"는
과장 없이 시설별로 다르게 나온다는 점이 이 결과의 신뢰도를 뒷받침한다.
