# 공급 지표 규격 (팀 공통)

`/dashboard`·`/simulator`가 지금까지 재던 건 **수요**(사회조사 "향후 필요" 응답률)
하나뿐이다. `data/facilities_*.csv` 6종을 **공급** 지표로 연결한다. 3개 트랙
(지도·시뮬레이터·코어)이 이 규격을 공유한다 — 각자 다른 방식으로 정규화하지 말 것.

## 공통 원칙

1. **좌표 → 행정동 매핑은 `app/geo.dong_for_point()` 하나만 쓴다.** 새로 짜지 말 것.
2. **정규화 단위** — `app/facilities.supply_by_dong()`이 반환하는 형태:
   | 시설 | 지표 | 근거 |
   |---|---|---|
   | 공영주차장·도서관·어린이집·약국 | 인구 **1,000명당 개소수** | 생활SOC 3개년 계획 공급 기준 |
   | 도시공원 | **1인당 공원면적(㎡)** — `PARK_AR` 합 / 인구 | WHO 권장 9㎡, 도시계획시설 결정기준 |
   | 병원 | 인구 **1,000명당 병상수** — `sickbd_cnt` 합 / 인구 | 보건의료 접근성 표준 |
3. **매핑 실패분**(`dong is None`)은 집계에서 제외하고, `unmapped_ratio()`로 품질을
   기록한다. 현재 실패율: 주차 0% / 도서관 0% / 공원 1.4% / 어린이집 4.9% /
   병원 2.1% / 약국 1.0%.
4. **격차 서사** — 공급도 수요와 같은 방향으로 본다:
   `공급격차 = 동안구 평균 공급 − 만안구 평균 공급` (양수면 만안구가 공급 부족).
   수요격차(만안 필요도 높음)와 공급격차(만안 공급 낮음)가 **같이** 크면 최우선 투자 대상.

## 새 시설 CSV 추가하는 법

`app/facilities.py`의 `REGISTRY`에 한 줄:
```python
"school": FacilitySpec("school", "facilities_school.csv", "<위도컬럼>", "<경도컬럼>", None, "학교", "개소"),
```
`weight_col`은 개소수 대신 합산할 컬럼(면적·병상수 등), 없으면 `None`.
